# narsimha-jammula-dev.github.io

Personal resume site, served via GitHub Pages at https://narsimha-jammula-dev.github.io/.

Plain static HTML/CSS, no build step. Content is also published in a few
machine-readable forms for automated/agentic readers:

- [`resume.json`](resume.json) — [JSON Resume](https://jsonresume.org) format
- [`resume.txt`](resume.txt) — plain text
- [`resume.pdf`](resume.pdf) — downloadable PDF
- [`llms.txt`](llms.txt) — summary for LLM crawlers

All facts are sourced from the author's own resume. No hidden text or
instructions aimed at automated screeners are present anywhere in this repo.
